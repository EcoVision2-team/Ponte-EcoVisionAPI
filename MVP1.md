# 📌 MVP - Projeto, construção e testes de pontes

## 🎯 Objetivo do MVP
> O objetivo do MVP foi desenvolver um vídeo de validação do entendimento do projeto, contemplando as principais etapas de pesquisa e definição da solução. Para isso, foram abordadas a pesquisa sobre pontes e alternativas estruturais, o levantamento dos requisitos e restrições, a comparação entre diferentes tipos de ponte, a escolha do modelo mais adequado e a justificativa técnica da solução escolhida.

## 🔑 User Stories (Backlog do MVP)
| ID  | User Story                                                                 | Prioridade | Estimativa |
|-----|-----------------------------------------------------------------------------|------------|------------|
| US1 | Quero pesquisar sobre pontes para compreender as alternativas estruturais disponíveis. | Alta | 3 |
| US2 | Quero levantar os requisitos e restrições do projeto para garantir que a solução atenda às condições da atividade. | Alta | 3 |
| US3 | Quero estudar alternativas de solução para comparar diferentes tipos de ponte antes de escolher o modelo. | Média | 2 |
| US4 | Quero escolher o tipo de ponte mais adequado para orientar o desenvolvimento do protótipo. | Alta | 2 |
| US5 | Quero justificar a solução escolhida para demonstrar as razões técnicas da decisão. | Alta | 2 |
